# Archived V1 Code Reference (閲覧用アーカイブ)

このフォルダーは、以前の実装コード（V1）を閲覧・参照用として保管しているアーカイブディレクトリです。

## 構成ファイル
- `server.ts`: プロセス隔離・状態自動永続化付きの Express バックエンドサーバー
- `App.tsx`: ポーリング同期・マルチタブ切り替え対応メイン UI
- `types.ts`: プログラム・実行ログ・環境変数の型定義
- `components/`: 各画面コンポーネント (Dashboard, ProgramManager, Scheduler, LogViewer, SyncManager, RailwayApi, TechSpec, Modals)
